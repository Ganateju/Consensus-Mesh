Consensus Mesh is a high-security presence verification ecosystem designed to eliminate proxy attendance through **environmental consensus**.

Instead of verifying credentials, Consensus Mesh verifies **shared physical reality** by combining **RF fingerprinting**, **indoor triangulation**, **temporal synchronization**, and **human liveness validation**.

If two devices are not observing the same environment, at the same moment, under the same physical conditions, they are not considered part of the mesh.

# 🌟 Core Innovation: Environmental Consensus Mesh

Consensus Mesh establishes trust through four independent dimensions of evidence.

### Spatial Consensus
Environmental similarity analysis through RF fingerprinting and indoor triangulation.

### Temporal Consensus
Universal synchronized challenge windows ensure simultaneous participation.

### Human Liveness
Cognitive response mechanisms combined with inertial verification.

### Distributed Peer Verification
Cross-device comparison identifies anomalous clusters and coordinated proxy behavior.

Together these mechanisms create an environmental proof of presence that is substantially harder to spoof than traditional credential-based attendance systems.

# 🔄 System Workflow

### 1. Scheduling
Admin provisions classroom schedules through the control center.

### 2. Anchoring
Teacher initializes a session and establishes environmental boundaries.

### 3. Synchronization
Student devices align to the global pulse clock.

### 4. Validation
Server computes similarity metrics and displacement values.

### 5. Challenge Distribution
Liveness challenges are broadcast simultaneously to all participants.

### 6. Consensus Formation
Environmental evidence is aggregated and evaluated.

### 7. Audit & Finalization
Potential anomalies are reviewed prior to attendance finalization.

# 📈 Mathematical Foundations

Consensus Mesh currently utilizes two primary proximity models.

## Cosine Similarity

Measures environmental fingerprint similarity.

```math
Similarity =
\frac{
\sum (S_v \cdot T_v)
}{
\sqrt{\sum S_v^2}
\cdot
\sqrt{\sum T_v^2}
}
```

---

## Euclidean Displacement

Measures radial deviation within the presence bubble.

```math
d=
\sqrt{
\frac{
\sum_{i=1}^{n}
(T_i-S_i)^2
}{n}
}
```
